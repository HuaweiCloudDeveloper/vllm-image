## 项目介绍
[vLLM](http://github.com/vllm-project/vllm)是一个快速且易于使用的LLM推理和服务库。vLLM最初由加州大学伯克利分校的天空计算实验室开发，现在已经发展成为一个由学术界和工业界共同共享的社区驱动项目。

本项目提供的开源镜像商品 [**vLLM大模型服务**](https://marketplace.huaweicloud.com/hidden/contents/f99f5fc8-4cf1-4dc9-92a7-8ffc4dd2805e#productid=OFFI1135139479874867200)，已预先安装vLLM推理框架及其相关运行环境，并提供部署模板。快来参照使用指南，轻松开启“开箱即用”的高效体验吧。

> **系统要求如下：**
> - CPU: 8vCPUs 或更高
> - RAM: 16GB 或更大
> - Disk: 至少 40GB
